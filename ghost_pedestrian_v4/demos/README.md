# v4 演示视频

四格布局（1280×720，20 fps，按仿真帧号对齐）：

| 位置 | 内容 |
|---|---|
| 左上 | 追尾视角（自车后方 8 m，随车运动）——看车辆轨迹、制动与碰撞 |
| 右上 | 俯视（自车上方后 6 m / 18 m 高）——看自车、遮挡 SUV、行人的几何关系 |
| 左下 | **LEAD 前视相机本体**（0.25, 0, 2.25，384×384，fov 60）——模型真实输入 |
| 右下 | 逐帧 HUD：时间/帧号、车速、油门/制动、行人被遮挡比例与是否在视场内、LEAD 辅助检测的行人置信度 |

| 文件 | 内容 |
|---|---|
| `demo_collision.mp4` | 20 m 触发：行人被 SUV 完全遮挡 → 进车道才暴露 → LEAD 碰撞 |
| `demo_safe.mp4` | 同场景 40 m 触发：更早释放，LEAD 安全通过 |
| `demo_oracle.mp4` | 20 m + Oracle（首次可见即全制动）：证明空间足够 |
| `demo_occluder_only.mp4` | 只有路侧停放的 SUV、无行人：场景基线 |
| `demo_comparison.mp4` | 上面四段的 2×2 对照 |

注意：左下是 LEAD 的**真实前视相机**，不是第三方视角的代理画面；它和模型
实际消费的 `rgb_2` 同位置、同分辨率、同 fov。行人的「被遮挡比例」也是从这个
相机位姿算出来的（见 `docs/GHOST_PEDESTRIAN_V4.md`）。
